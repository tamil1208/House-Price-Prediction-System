📌 Price Analysis Insights

  • Area is the #1 driver — larger properties consistently command higher prices (correlation: 0.536).
  • Bathrooms multiply value steeply — 4-bathroom homes average ₹122.5L vs ₹42.1L for 1 bathroom (3× premium).
  • Stories add steady value — each additional story adds ₹5–15L on average.
  • AC premium is 43% — AC homes average ₹60.1L vs ₹41.9L without AC.
  • Furnished homes command 37% more than unfurnished (₹54.9L vs ₹40.1L).
  • 6-bedroom homes drop below 5-bedroom — oversized properties face a pricing ceiling.

📌 Model Performance Insights

  • Linear Regression (R²=0.653) outperforms Random Forest (R²=0.612) — the dataset has a moderately linear structure.
  • MAE of ₹9.7L means predictions are off by ~₹9.7L on average — within acceptable range for real estate estimates.
  • Random Forest underestimates luxury properties (>₹100L), visible in the scatter plot where points fall below the diagonal.
  • Residuals are approximately normally distributed around 0, indicating no major systematic bias in the Linear Regression model.

📌 Key Discoveries & Surprises

  • Surprise: Linear Regression beat Random Forest (65.3% vs 61.2% R²) — this dataset has a sufficiently linear price-feature structure that the simpler model generalizes better.
  • Discovery: 6-bedroom homes (avg ₹47.9L) are worth less than 5-bedroom homes (avg ₹58.2L) — oversized properties face a valuation ceiling, likely due to limited buyer pool.
  • Pattern: Main-road access adds ~47% to average price (₹49.9L vs ₹34.0L) — location connectivity is a powerful hidden value driver.
  • Model Gap: Both models struggled with luxury properties (>₹100L), underestimating extreme prices — non-linear dynamics emerge at the top end.
  • Recommendation: XGBoost + feature engineering (price/sqft ratio, bath-to-bed ratio, multi-amenity score) could push accuracy above 80% R².
